# CxSolutionEngineering

## About

This organization is a collection of intentionally vulnerable applications, demonstration repositories, and similar test assets. The repositories here exist to support demos, testing, training, and validation of security tooling.

## What You Will Find Here

- Applications with deliberately introduced vulnerabilities, such as insecure code, vulnerable dependencies, and misconfigurations
- Fixtures containing hardcoded secrets for testing detection and validation
- Sample projects used to walk through scan results, remediation workflows, and reporting
- Supporting scripts and configuration that help set up the demo assets above

## Important Notes

- **Do not use anything here in production.** The code in these repositories is insecure by design.
- **Do not host real-world tools here.** This organization does not apply the controls required for production or internal tooling, so such tools belong elsewhere.
- **Do not commit real credentials, customer data, or sensitive information.** Any secrets in these repositories must be fake, or minimally permissioned and disposable.
